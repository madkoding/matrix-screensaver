Gratis · Windows 10/11 · unos 30 MB · todas las versiones

Tres monitores, cada uno con su propia lluvia.

Qué incluye

Creado desde cero con Python y OpenGL.

Multimonitor y sensible al DPI

Cada pantalla ejecuta su propia lluvia, ajustada a su tamaño, posición y escala. Conecta o desconecta una pantalla mientras funciona.

El aspecto de la película

Katakana de medio ancho en espejo más dígitos, una cabeza casi blanca, una estela verde que se desvanece y glifos que mutan.

Profundidad y brillo

Tres capas con paralaje (una lejana y tenue, una intermedia y una cercana, grande y desenfocada) con bloom real.

Sensación de CRT

Scanlines con interlazado animado, viñeteado y un parpadeo sutil.

Wake up, Neo…

De vez en cuando un mensaje se escribe solo sobre la lluvia.

Rápido y ajustable

Funciona en la GPU (unos 700 FPS sin tope en una RTX 3060) con respaldo automático por software, además de seis colores y una ventana de ajustes.

Descarga e instalación

Toma alrededor de un minuto. Sin instalador ni cuenta.

  1. Descarga MatrixRain.scr

    Pulsa el botón de arriba, o búscalo en la página de la última versión (el archivo está en Assets).

  2. Haz clic derecho sobre el archivo y elige Instalar

    Windows abre la ventana Configuración del protector de pantalla con él ya seleccionado. Si Windows pide permisos de administrador, acéptalos: copia el archivo donde viven los protectores de pantalla.

  3. Pulsa Aplicar y Aceptar

    En Esperar elige cuántos minutos de inactividad quieres. Usa Vista previa para probarlo al instante; cualquier tecla o movimiento del ratón lo cierra.

  4. Opcional: pulsa Configuración… para ajustarlo

    Seis colores (verde película, clásico, ámbar, rojo, azul, blanco), brillo, scanlines, velocidad de caída, densidad, tamaño de glifos y más. Incluso puedes usar una fuente propia.

¿Windows dice «protegió su PC»? El archivo no está firmado digitalmente (hace falta un certificado de pago), así que SmartScreen o tu antivirus pueden avisar, como con muchas herramientas pequeñas. Pulsa Más información → Ejecutar de todas formas. Si el menú del clic derecho no tiene Instalar, haz clic derecho → Propiedades → marca Desbloquear → Aceptar primero. Puedes leer todo el código en GitHub y compilarlo tú mismo.
¿No encuentras la ventana del protector de pantalla?

Pulsa la tecla Windows y escribe protector de pantalla, y abre Cambiar protector de pantalla. En Windows 11 también está en Configuración → Personalización → Pantalla de bloqueo → Protector de pantalla. Elige Matrix Screensaver en la lista desplegable.

Instalar a mano (copiar el archivo)

Copia MatrixRain.scr a C:\Windows\System32 (requiere permisos de administrador). Aparecerá en la lista de protectores de pantalla.

Ejecutarlo desde el código 
git clone https://github.com/madkoding/matrix-screensaver.git
cd matrix-screensaver
python -m pip install -r requirements.txt
python matrix_saver.py /s

Necesitas Python 3.10+ en Windows. Para compilar tu propio MatrixRain.scr ejecuta .\build.ps1 (mira el README).

Desinstalar

Abre otra vez la ventana del protector de pantalla y elige otro (o (Ninguno)). Para borrar el archivo, elimina MatrixRain.scr de la carpeta donde lo copiaste (normalmente C:\Windows\System32). Tus ajustes están en %APPDATA%\MatrixRain; borra esa carpeta para restablecerlos.
